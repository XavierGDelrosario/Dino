Google's official "translated by Google" attribution badges, unmodified, from the pack
linked on https://cloud.google.com/translate/attribution
(`google-translate-attribution.zip` → `png/`: the colour, greyscale and white "short"
variants at 1x/2x/3x). Google's rules: shown beside a translation it produced, linked to
https://translate.google.com, always whole and clearly visible, never altered.

PNG, not the pack's SVG, on purpose: the SVGs draw "translated by" as live text in
Roboto, which Apple devices don't have, so a browser there substitutes its own font and
the badge is no longer Google's lettering. The PNGs are pre-rendered with the right one.
